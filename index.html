Final Year Project · BAXU 3973

Net-Guardian: Gamified IDS Training

A tower defense game that teaches intrusion detection. Incoming network attacks are the "enemies"; players defend by deploying towers mapped to IDS signatures, learning which signature catches which attack.

  • Designed a Signature-to-Tower (STG) gamification framework mapping IDS signatures to game mechanics
  • Built in Unity WebGL so it runs in the browser, with a PHP REST API backend over a six-entity database
  • Followed OOAD: use case, activity, architecture, ERD, flowchart and UI mockup designs
